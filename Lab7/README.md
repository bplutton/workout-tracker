# workout-tracker
OOP workout tracking system

## Project Description

### What the System Does
This system lets the user enter information about a workout and get a workout summary.

### What OOP concepts it demonstrates
Inheritance - Creating class hierarchies with shared and specialized behavior
Composition - Building complex objects from simpler ones
Encapsulation - Protecting data with appropriate access control

## Installation

bash
pip install -e .

## Running Tests

bash
pytest

## Running Demo

bash
python main.py
